# User Manual screenshots

Drop screenshots here using the **exact path** below. Each figure in the in-app
manual (`/user-manual`) is already wired to its file — the moment the file
exists, it replaces the dashed "screenshot to be added" placeholder. A missing
file just keeps showing the placeholder, so partial coverage is fine.

## Capture settings (keep consistent)

- Browser width ~1440px, **light theme**
- One image set is shared across all three languages (en / fa / ps); only the
  captions differ. Use whichever UI language you like — Dari is fine.
- Crop tight to the relevant area, not the whole page.
- Demo/sample data only — no real customer names or amounts.
- PNG, ≤ 1600px wide, aim < 300 KB.
